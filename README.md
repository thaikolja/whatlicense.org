# whatlicense.io

Find the perfect open-source license for a project. Answer a few simple questions and get an instant recommendation with
ready-to-use file headers.

![whatlicense.io Preview](https://whatlicense.io/og-image.png)

## Features

- **Weighted Matching Engine**: A sophisticated algorithm that scores licenses based on project needs (copyleft,
  commercial use, etc.).
- **25+ Licenses**: Comprehensive database of popular open-source licenses.
- **File Header Generator**: Customize your code headers with project details and custom `@property` tags.
- **Premium Design**: A high-fidelity, responsive interface built for developers.
- **Fast & Private**: All matching and customization happen locally in your browser.

## Tech Stack

- **Framework**: [Nuxt 4](https://nuxt.com)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com)
- **Content**: [@nuxt/content v3](https://content.nuxt.com)
- **Icons**: Heroicons & Custom SVGs
- **Typography**: Playfair Display & Karla (Google Fonts)

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
